# 開發順序

一次只做一項。開新對話，貼：

```text
/poteto-mode
做 docs/DEV_TODO.md 第 N 項。
規格只讀 docs/REFACTOR_PLAN.md 裡同一個編號的那一條，以及 §16 有點名時的那一小節。
不要做下一項，不要重開 /architect。
```

做完你確認，再做下一項。`REFACTOR_PLAN.md` 裡標〔取消〕或〔併入〕的編號不要另開。
